## Grouped by Functional Area

### Authentication & Security (Out of Scope)
- Email-based user login only
- Email OTP on every login (MFA)
- Forget Password flow
- Password modification via OTP verification
- Password policy display on update page
- Forced password change on first login
- Password policy: minimum 15 characters, uppercase, lowercase, numeric, and special characters
- Password expiry: every 30 days

### Dashboard (Out of Scope)
- Total sites count

- Excel report download per category
